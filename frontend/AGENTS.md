# React frontend

This frontend uses React, TypeScript, Vite and React Router. There are no Next.js runtime APIs or server components.
Read ../DESIGN.md before visual changes and preserve its Vietnamese fonts and tokens. Keep source/tests readable, with descriptive names and multiline JSX.
Follow the workspace AGENTS.md: no manual backend edits, no commit/push without current explicit authorization.
Validation commands: npm run lint, npm run typecheck, npm test, npm run build. Browser suites use Playwright with isolated localhost ports; do not log session tokens, roles or cards.
